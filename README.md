# Лабораторная работа №2: Камера и освещение

Вариант 12: правильный гексаэдр (куб). Работа сделана на основе лабораторной работы №1 и стартового проекта [vulkan-starter-app](https://github.com/vladeemerr/vulkan-starter-app) (C++, Vulkan, GLFW, Dear ImGui, GLM).

## Задание

Сделать камеру, которую можно перемещать, и освещение по модели Блинна-Фонга с несколькими типами источников света. Камера, источники и материалы объектов настраиваются в реальном времени через ImGui.

## Что сделано

**Базовое задание**
- Камера: позиция, поворот (yaw / pitch), угол обзора, ближняя и дальняя плоскости, перспективная и ортографическая проекция. Матрица вида считается как обратная к матрице «модели» камеры (лекция 4).
- Вершина содержит позицию, нормаль и цвет. Нормали генерируются процедурно (`generateFlatNormals`): нормаль грани — нормированное векторное произведение двух рёбер треугольника.
- Во фрагментном шейдере реализована модель Блинна-Фонга по формуле из лекции: `[albedo + specular · (n·h)^alpha] · (n·l) · E`.
- Есть направленный источник света (направление, цвет, интенсивность, вкл/выкл) и рассеянный свет (цвет, интенсивность).
- У каждого объекта настраивается материал: альбедо, цвет блика и коэффициент блеска `alpha`.

**Дополнительные задания**
1. Два набора дескрипторов, как в лекции. `set = 0` — сцена: uniform `SceneUniforms` (`view_projection`, позиция камеры, направленный и рассеянный свет, число источников) и два storage-буфера с массивами источников. `set = 1` — модель: uniform `ModelUniform` (`model`, `albedo`, `specular`, `alpha`).
2. Массив точечных источников в storage-буфере (`binding = 1`), затухание по закону обратных квадратов. В интерфейсе источники можно добавлять, удалять, менять их параметры и включать вращение вокруг сцены.
3. Массив прожекторов в storage-буфере (`binding = 2`), затухание по закону обратных квадратов. Край пятна мягкий: между внутренним и внешним углом яркость плавно падает до нуля. Прожекторы тоже добавляются и удаляются в интерфейсе, а любой из них можно прикрепить к камере как фонарик.
4. Визуализация источников, которую можно скрыть флажком *Show lights*. Точечный источник и прожектор показаны яркой сферой цвета источника, у прожектора ещё рисуется конус белыми линиями: внешний угол, внутренний угол серым и ось направления. Визуализация рисуется отдельным конвейером (`light.vert` / `light.frag`) без освещения.

Размер массивов источников в шейдере не задаётся: storage-буферы на CPU сами увеличиваются, когда источников становится больше.

Сцена: три куба из лабы 1 с разными материалами, которые движутся по той же траектории.

## Управление

| Действие | Как |
|---|---|
| осмотреться | зажать правую кнопку мыши и двигать мышь |
| двигаться | W / A / S / D, вверх и вниз — E / Q, быстрее — Shift |
| угол обзора | колесо мыши |

Окно **Camera & Objects** — камера, анимация, объекты и материалы. Окно **Lights** — визуализация, рассеянный свет, направленный свет, точечные источники и прожекторы (кнопки *Add* и *Remove*).

## Структура

```
shaders/
  shader.vert / shader.frag   освещаемые объекты (блинн-фонг)
  light.vert  / light.frag    визуализация источников
source/
  application.cpp             сцена, интерфейс, ресурсы vulkan, отрисовка
  graphics_internal.cpp/.hpp  стартовый код (окно, swapchain, imgui)
  main.cpp
```

## Сборка и запуск (Windows, Visual Studio 2022)

Нужны Visual Studio 2022 с рабочей нагрузкой «Разработка классических приложений на C++», Vulkan SDK (в нём есть GLM и glslc) и интернет при первой настройке CMake.

1. Путь к Vulkan SDK указан в `CMakePresets.json` (`D:/lAB_CG/...`). Если SDK стоит в другом месте, поправьте этот путь.
2. В Visual Studio выберите **Файл → Открыть → Папка** и укажите папку проекта.
3. Дождитесь, пока закончится настройка CMake.
4. **Сборка → Собрать всё.** Шейдеры компилируются в `shaders/*.spv` автоматически.
5. Выберите цель `vulkan-starter-app.exe` и нажмите F5.
